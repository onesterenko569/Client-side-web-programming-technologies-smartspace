# Лабораторна робота №3

**Дисципліна:** Клієнтські технології Web-програмування 
**Тема:** Розробка вебсторінки засобами HTML5: таблиці, списки, медіа та навігація 
**Виконав:** Нестеренко Олександр, група ІН-41/1

## Опис проєкту

У межах цієї лабораторної роботи односторінковий каркас каталогу техніки "SmartSpace" (з ЛР №2) було розширено до повноцінного багатосторінкового сайту з трьох пов'язаних сторінок. Проєкт реалізовано виключно засобами чистого HTML5 без використання таблиць стилів та скриптів, із суворим дотриманням семантичних вимог, стандартів доступності та підтримки сучасних медіаформатів.

## Структура файлів проєкту:

* `index.html` — головна сторінка каталогу (з ЛР №2, оновлена посиланнями на деталі та групуванням фільтрів);
* `details.html` — сторінка детального опису товару з адаптивними зображеннями, списком характеристик та таблицею порівняння;
* `about.html` — сторінка "Про проєкт" із покроковою інструкцією, відеопрезентацією, субтитрами та блоком FAQ;
* `favicon.ico` — піктограма сайту;
* `images/` — папка з графічними ресурсами, включаючи зображення у форматах JPEG та WebP;
* `media/` — папка з медіафайлами (`promo.mp4`, `promo.webm`) та файлом українських субтитрів (`subtitles.vtt`).

## Основні виконані етапи:

* **Багатосторінкова архітектура та навігація:** створено пов'язану систему сторінок на основі відносних шляхів; на всіх сторінках реалізовано єдину шапку, підвал та меню `<nav>` з атрибутом `aria-current="page"` для позначення поточної сторінки;
* **Розширення можливостей сторінки деталей (`details.html`):** додано хлібні крихти (`<ol>`), внутрішню якірну навігацію, адаптивні зображення через `<picture>` та `<srcset>`, список описів характеристик (`<dl>`), а також доступну таблицю модифікацій із заголовками `scope`;
* **Розробка сторінки "Про проєкт" (`about.html`):** оформлено інструкцію користувача, марковані й нумеровані списки, медіаелемент `<video>` з панеллю керування, доріжкою субтитрів `<track>` і резервним вмістом, а також групу інтерактивних елементів `<details name="faq">` та блок `<address>`;
* **Контроль доступності та валідності:** код кожної сторінки успішно перевірено за допомогою W3C Validator без помилок та проведено аудит доступності;
* **Контроль версій:** реалізацію проєкту поділено на логічні етапи та зафіксовано системою комітів у гілці `lab3` віддаленого репозиторію на GitHub.
