# Практична робота №2

**Дисципліна:** Клієнтські технології Web-програмування  
**Тема:** Семантична розмітка HTML5 та адаптивні зображення  
**Виконав:** Нестеренко Олександр, група ІН-41/1

## Опис проєкту

У межах цієї лабораторної роботи створено семантичний HTML-каркас для вебсторінки каталогу техніки "SmartSpace" із дотриманням сучасних стандартів доступності та адаптивності.

## Основні виконані етапи:

* **Семантична розмітка:** застосовано теги `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` та `<footer>` без використання несемантичних контейнерів `<div>`;
* **Адаптивні зображення:** реалізовано механізм економії трафіку залежно від ширини екрана за допомогою атрибутів `srcset` та `sizes`;
* **Доступність:** додано атрибути `aria-label` для навігації та `alt` для зображень;
* **Контроль якості:** код успішно пройшов перевірку через W3C Validator без попереджень та помилок;
* **Аналіз DevTools:** перевірено DOM-дерево, ієрархію заголовків та наявність необхідних атрибутів безпосередньо у браузері.
